# Plub-Supanut Project Standard

มาตรฐานกลางสำหรับทุก repo ของ **Plub-Supanut** — ใช้เป็น checklist ตั้งแต่ตั้ง repo จนถึง release
เพื่อให้ทุกโปรเจกต์เปิดมาดูแล้วรู้ทันทีว่าคืออะไร ใช้ยังไง และเชื่อถือผลลัพธ์ได้

## เอกสาร

- **[GITHUB_STANDARD.md](GITHUB_STANDARD.md)** — มาตรฐานฉบับเต็ม (metadata, README, release, CI, license)

## หลักจำง่าย

ทุกโปรเจกต์ต้องมี **release**, ทุก release ต้องมี **notes**, ทุก repo ต้องมี **README ที่พร้อมให้คนอื่นเปิดดู**

## ใช้งาน

- ตั้ง repo ใหม่: ทำตามหัวข้อ Definition of Done ใน [GITHUB_STANDARD.md](GITHUB_STANDARD.md)
- ก่อน release: ใช้ checklist หัวข้อ Release ในเอกสารเดียวกัน
- README ทุก repo ควรมีรูปแบบเดียวกับ [ECG Field Guide](https://github.com/Plub-Supanut/ecg-field-guide): banner, badges, quick links, overview, quick start, features, structure, development, standard, attribution, license
